رحلة صغيرة اتعملت مخصوص لدعاء (دودي) في عيد ميلادها العشرين… من أمير.

## ▶️ التشغيل محليًا

### الطريقة الأسهل

```bash
node serve.js
```

وبعدها افتحي: <http://localhost:4173>

> لازم تشغّلي الموقع من سيرفر محلي (مش بالدبل كليك على `index.html`)، عشان الخطوط والموسيقى والـ service worker يشتغلوا صح.

أي سيرفر ثابت تاني ينفع، مثل:

```bash
npx serve .
# أو
python -m http.server 4173
```

### المميزات

- **موبايل أولًا** ومتوافق مع Android Chrome والشاشات الكبيرة.
- **RTL** بالكامل، بخطوط عربية محلية: `Tajawal` و`Aref Ruqaa`.
- **موسيقى محلية**: أغنية عيد الميلاد + `Rewrite The Stars`. مش بيشتغلوا مع بعض أبدًا.
- **عدّاد القاهرة** (`Africa/Cairo`) من 21/11/2006، بيتحوّل لوحده من عدّ تنازلي لعدّ تصاعدي بعد بداية اليوم.
- **Offline** عبر `sw.js` بعد أول زيارة.
- **بدون صور**: كل الأشكال SVG / CSS / Canvas.
- احترام `prefers-reduced-motion` وتباين مقروء.

## 🚀 النشر

الموقع **ثابت 100%**، فممكن يترفع على أي استضافة ثابتة. المسارات كلها نسبية، يعني بيشتغل من جوه فولدر (subpath) كمان.

### GitHub Pages

1. اعمل ريبو جديد وارفع الملفات.
2. من **Settings → Pages** اختار **Deploy from a branch** → `main` → `/ (root)`.
3. استنى دقيقة، والرابط هيبقى:

```
https://<username>.github.io/<repo>/
```

### Vercel

```bash
npx vercel
```

أو اربط الريبو من لوحة Vercel. مفيش build command ولا output directory مطلوبة — الملفات جاهزة.

### ملاحظة

الـ `serve.js` و`sw.js` اختياريين للنشر الثابت: `serve.js` للتشغيل المحلي بس، والـ service worker بيدّي تجربة offline بعد أول زيارة.
